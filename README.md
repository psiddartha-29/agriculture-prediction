# Agricultural Yield Prediction and Productivity Factor Analysis

Predicts crop yield (plus fertilizer and pesticide quantity) from Indian crop-production data and serves the models through a FastAPI app.

## Project structure

```
PS1/
├── README.md
├── requirements.txt
├── .gitignore
├── .vscode/settings.json
│
├── data/
│   ├── raw/crop_yield.csv               # original dataset (19,689 records) - never edit
│   └── processed/                       # generated by the pipeline
│       ├── crop_yield_processed.csv     # cleaned data, converted units   (02)
│       ├── Fertilizer.csv               # fertilizer-model dataset        (03)
│       └── Pesticide.csv                # pesticide-model dataset         (03)
│
├── src/                                 # pipeline scripts - run in numeric order
│   ├── 01_eda.py
│   ├── 02_preprocessing.py
│   ├── 03_split_fertilizer_pesticide_data.py
│   ├── 04_yield_model.py
│   ├── 05_fertilizer_model.py
│   └── 06_pesticide_model.py
│
├── models/                              # trained models + metrics
│   ├── best_yield_prediction_model.pkl
│   ├── fertilizer_prediction_model1.pkl
│   ├── pesticide_prediction_model.pkl
│   ├── model_comparison.csv
│   ├── tuning_comparison.csv
│   └── final_test_metrics.csv
│
├── api/                                 # FastAPI app
│   ├── main.py
│   └── sample_request.json
│
└── reports/figures/                     # saved plots (optional)
```

## Setup

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Run the pipeline (from the project root `PS1/`)

```powershell
python src/01_eda.py
python src/02_preprocessing.py
python src/03_split_fertilizer_pesticide_data.py
python src/04_yield_model.py
python src/05_fertilizer_model.py
python src/06_pesticide_model.py
```

## Run the API (from the project root `PS1/`)

```powershell
uvicorn api.main:app --reload
```

Open http://127.0.0.1:8000/docs. Endpoints: `GET /`, `GET /health`, `POST /predict`, `POST /predict/fertilizer`, `POST /predict/pesticide`. An example request body is in `api/sample_request.json`.

## Notes

- All scripts find files relative to the project root, so they work from any working directory.
- Yield units are a working assumption (original Yield treated as t/ha, converted to kg/acre); confirm against the dataset documentation before reporting.
- `.gitignore` excludes `data/processed/*` and `models/*`, so regenerate them with the pipeline.
